# 🚗 Car Rental System (CLI)

A simple Car Rental System developed in Java using Object-Oriented Programming (OOP) concepts.

## 📌 Features

- Add Cars
- Show Available Cars
- Rent a Car
- Return a Car
- Basic Customer Management

## 🛠 Technologies Used

- Java
- OOP
- Arrays of Objects
- CLI (Command Line Interface)

## 📚 OOP Concepts Used

- Classes & Objects
- Constructors
- Encapsulation
- Has-A Relationship
- Array of Objects

## 🚀 Future Improvements

- Menu Driven System
- Rental History
- Search Customer
- Duplicate Car Validation
- Better Input Validation
